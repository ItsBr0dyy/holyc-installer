## Dependencies

- Git
- Make

## Installation

Windows:
```powershell
irm https://raw.githubusercontent.com/itsbr0dyy/holyc-installer/main/windows/installer.ps1 | iex
```

macOS:
```Terminal.app
curl -fsSL https://raw.githubusercontent.com/itsbr0dyy/holyc-installer/main/macos/installer.sh | bash
```

Linux:
```bash
curl -fsSL https://raw.githubusercontent.com/itsbr0dyy/holyc-installer/main/linux/installer.sh | bash
